English

This is an automation system I built with Python. It shows you, using a rating system, whether an email you receive is a phishing attempt. To be honest, I used AI for about 45% of this project.

How do you use the system?

Open the ZeroPhish application with a double-click.
Download the suspicious email in .eml format and place it on your desktop or inside the ZeroPhish folder.
If it’s inside the folder, the system will detect it automatically and show you the analysis.
If you downloaded it to your desktop or somewhere else, don’t worry—drag and drop the file into the terminal, and ZeroPhish will analyze it.
